# نظام تذاكر الدعم الفني عبر التيليجرام 🎫

نظام داخلي متكامل لإدارة التذاكر والدعم الفني للشركات الصغيرة عبر بوت تيليجرام مع لوحة تحكم ويب محلية.

---

## 🚀 طريقة التشغيل السريع:

### 1. تشغيل البرنامج:
- اضغط مرتين على ملف **`run.bat`**.
- سيفتح السيرفر والمتصفح تلقائياً على الرابط:
  ```
  http://localhost:8000
  ```

### 2. تفعيل توكن البوت:
- يمكنك إدخال التوكن مباشرة من نافذة الإعدادات داخل لوحة التحكم.
- أو كتابته في ملف **`.env`**:
  ```env
  TELEGRAM_BOT_TOKEN=7123456789:AAHq_...
  ```

---

## 🌟 المميزات:
1. **استقبال التذاكر التلقائي:**
   - بمجرد أن يرسل أي مستخدم رسالة إلى البوت، يتم فتح تذكرة جديدة برقم فريد (مثل `#TK-1001`).
   - يرسل البوت للمستخدم زر تفاعلي فوري: `📱 مشاركة رقم هاتفي لتأكيد التذكرة`.
2. **شات ثنائي مباشر (Two-Way Communication):**
   - الرد المباشر من لوحة التحكم يصل فوراً كرسالة من البوت للمستخدم.
   - أي رسالة جديدة يرسلها المستخدم تضاف إلى نفس التذكرة وتُصدر تنبيهاً صوتياً في اللوحة.
3. **دعم الصور ولقطات الشاشة:**
   - لو أرسل المستخدم صورة أو Screenshot للمشكلة، يتم تنزيلها وعرضها فوراً في شات لوحة التحكم مع إمكانية تكبيرها.
4. **تغيير حالة التذكرة:**
   - (جديدة 🟡 / قيد المعالجة 🔵 / تم الحل 🟢 / مغلقة ⚪) مع إشعار المستخدم تلقائياً عند حل المشكلة وإغلاقها.
5. **مشاركة اللوحة على شبكة الشركة:**
   - السيرفر يستمع على `0.0.0.0`، مما يتيح لأي جهاز كمبيوتر أو لابتوب متصل بنفس الراوتر فتح اللوحة عبر:
     `http://[IP-الكمبيوتر]:8000`
